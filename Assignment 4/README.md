# My Portfolio

A simple portfolio website made with HTML and CSS. It introduces me, my education, the skills I’m learning, and my first project.

## Files

- `index.html` — portfolio content
- `style.css` — page styles

## Design Choices

I chose Playfair Display for headings and DM Sans for body text because they are easy to read. Cream and dark gray create a calm background, green highlights links, and coral adds a small accent.
