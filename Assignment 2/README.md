# Job Application Form

A responsive HTML and CSS job application form created for First Semester MERN Assignment 2. It demonstrates common form controls, labels, grouping, and built-in HTML validation.

## Files

- `index.html` — form markup and a small script that updates the range value.
- `style.css` — responsive page styling.

## Open the form

Keep both files in the same folder, then open `index.html` in a web browser.

## Form controls included

- Text, email, password, telephone, URL, and number fields
- Radio buttons, checkboxes, a select menu, and a datalist
- Date, time, file, range, color, and textarea fields
- Labels linked to controls, grouped with fieldsets and legends
- Required fields and validation using `min`, `max`, `minlength`, and `pattern`
- Submit and reset buttons
