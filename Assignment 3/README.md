# School Cricket Scoreboard

A beginner HTML and CSS project that displays a cricket scoreboard in a table.

## Features

- 20 player rows across 10 columns
- Table caption, header, body, and footer
- Uses `rowspan` and `colspan`
- CSS variables for colors and spacing
- Striped rows and a hover effect

## Files

- `index.html` — scoreboard table
- `style.css` — table styling
